# My6502
Index of my 6502 and W65C816 designs in GitHub. Designs are listed chronologically with links to respective repositories

### [3V6502](https://github.com/Plasmode/3V6502)
Circa 2024. A W65C02 based mezzanine board designed for EPM240 Development board. It is runs at 25MHz to drive monochrome 640x480 VGA display with software beam racing. It has sufficient processing capacity remain to receive PS2 keyboard input, process serial I/O, SD card interface, and RTC interface. Discussion in [retrobrew computer forum](https://www.retrobrewcomputers.org/forum/index.php?t=msg&th=810&goto=10817&#msg_10817)
